# PWA-GoogleDrive v0.1.8

Cloud efficiency milestone: persistent, account/folder-scoped positive object index; bounded expiry and read repair; targeted name queries; per-session bounded hash cache; large-push deduplication preflight; large-section PUT fallback; content-free diagnostics and safe read retries. Immutable revision formats, SHA-256 verification, local-first writes and retention policy are unchanged. Pruning timestamps are now per app folder. See README for caveats about manual Drive edits and reported foreground metrics.
